# Claude Plugin Directory listing

## Name

Lycatra

## Description

Connect Claude Cowork and Claude Code to your Lycatra agents, wiki, persistent memory, schedules, notifications, Matrix collaboration, and team task boards. Installation is plugin add followed by Lycatra OAuth; Claude Code starts the verified local Lycatra bridge automatically.

## Use cases

- Search and update personal or organization wiki knowledge.
- Inspect accessible agents and work with their persistent memory.
- Schedule one-time or recurring agent work.
- Coordinate multi-agent teams, task boards, and shared state.
- Review notifications and send Matrix messages from Lycatra.
- Use the public Lycatra CLI families automatically from Claude Code.

## Platforms

- Claude Cowork
